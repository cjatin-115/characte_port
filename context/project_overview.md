## Experience qualities

Editorial, celestial, monochrome, atmospheric, asymmetric, restrained. A recurring celestial object ties the hero and later details together. Motion has purpose, degrades for reduced-motion/touch and never blocks content. The eventual loading experience uses an owner-supplied video; until then implement readiness/failure architecture only.
