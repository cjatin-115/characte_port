# Grid and Composition

- Shared page gutter is fluid via `--gutter`; components align to it unless an intentional full-bleed composition is specified.
- Use a wide editorial canvas with deliberate negative space and asymmetric image/metadata relationships.
- The hero's orbital geometry is decorative and absolutely positioned behind readable text; content keeps a stable DOM order.
- Project index uses a semantic list and columns that collapse to a touch-readable mobile composition.
- Avoid a fixed desktop canvas or horizontal page overflow at narrow widths.
