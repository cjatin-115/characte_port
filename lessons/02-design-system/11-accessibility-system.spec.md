# Accessibility System

- Provide skip navigation, native links, semantic landmarks, visible keyboard focus, route state, labels, and readable status/error text.
- Reduced motion disables smooth scrolling and collapses optional transitions.
- Hover is never the only route to information; controls retain touch equivalents.
- Text remains DOM content over decorative CSS geometry; decorative artwork is hidden from assistive technology.
- Include keyboard, contrast, screen-reader semantics, and narrow viewport checks in each feature's QA.
