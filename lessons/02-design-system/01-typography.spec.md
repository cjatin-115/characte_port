# Typography System

- Keep three named roles: `--font-display`, `--font-interface`, `--font-technical`.
- Current phase uses resilient system sans for display/interface and platform monospace for metadata; no remote font requests.
- Scale is tokenized as `--type-label`, `--type-body`, `--type-heading`, `--type-display`; the display scale responds to viewport size.
- Use optical hierarchy, moderate tracking for labels, and readable line lengths; avoid all-caps body text.
- Revisit a custom self-hosted display face only after visual exploration and a font budget review.
