# Responsive System

- Current primary breakpoint is 760px; desktop and mobile navigation/layout are composed deliberately.
- Navigation wraps into a second compact row on mobile; project rows reflow title and repository metadata.
- Hero orbital geometry can extend off-canvas inside a clipped hero region, but page content must not create horizontal scrolling.
- Fluid gutter/type tokens adapt composition. Touch targets, text size, and reading order take priority over visual symmetry.
- Validate future layouts at narrow phone, broad phone, tablet, and desktop widths.
