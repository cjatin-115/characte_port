# Color System

- Base: deep warm black `--ink`, raised black `--ink-raised`, warm light `--paper`, softer text `--paper-soft`, muted gray `--muted`.
- One restrained warm accent `--accent`; never rely on color alone for state.
- Rules and accent surfaces use transparent derivatives to preserve texture/contrast.
- All interactive/focus states retain readable contrast and are checked after actual content is placed.
