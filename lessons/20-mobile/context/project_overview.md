# Mobile Project Overview

## Purpose

Provide secure mobile access to the private control ecosystem.

## Primary Functions

- music playback
- background playback
- lock-screen controls
- vault access
- dashboard overview
- notifications
- quick actions

## Non-Goals

This application does not reproduce the public portfolio.

## Priority

1. security
2. reliable playback
3. offline resilience
4. battery efficiency
5. usability
6. visual consistency
